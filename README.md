# STUDENT-DATA-ANALYSIS
## DESCRIPTION
The data analysed was downloaded from https://www.kaggle.com/datasets/sadiajavedd/students-academic-performance-dataset
### FEATURES
It contains the following fields: gender, race, parental level of education, maths, reading and writing scores
The data was analysed using Microsoft Excel 
#### TOOLS USED
Pivot tables, pivot charts, IF AND statement. These tools were used to compute the grade and final class of degree for each student
#### INSIGHTS
From the analyzed data, it can be inferred that you will graduate with a first class if your parent has an associate degree which is 44.7% probable
